Privacy Policy — Email Reply Assistant

Last updated: 2026-07-05

"Email Reply Assistant" is a personal-use application built and operated solely by this site's owner, for their own Gmail account. It is not distributed to, or used by, any other person.

What it accesses

The app requests exactly one Google API scope: gmail.send (and a metadata-only read scope, gmail.metadata, used only to correctly thread a reply to the message it responds to — subject, message ID, and thread ID; never the body of any email). It cannot read your inbox contents, contacts, or any other Google data.

How it's used

The app sends a single email message only when the account owner explicitly reviews and approves that exact message's content in a live, interactive session. It never sends anything automatically, on a schedule, or without that explicit per-message approval.

How data is stored

The only credential stored is an OAuth refresh token, kept in a restricted-permission file on a private server controlled solely by the account owner. No email content, contact information, or other Google data is stored, logged, or retained anywhere.

Sharing

No data is shared with, sold to, or processed by any third party. This application communicates only with Google's own APIs.
